## Deploy to GitHub Pages

1. Create a repo named `kumudini100.github.io` on GitHub
2. Upload ALL files in this folder
3. Go to **Settings → Pages → Branch: main → Save**
4. Live in ~2 minutes at `https://kumudini100.github.io`

## ⚠️ Before uploading — 2 things to do:

### 1. Add your resume PDF
Rename your resume file to exactly:
```
Kumudini_Gandesiri_Resume.pdf
```
And place it in this folder alongside `index.html`.

### 2. Set up Google Analytics (free)
- Go to https://analytics.google.com
- Create a property → get your **Measurement ID** (looks like `G-XXXXXXXXXX`)
- In `index.html`, replace both instances of `G-XXXXXXXXXX` with your real ID
- Now you'll see who visits, where they come from, and if they download your resume

## Optional: Custom Domain
If you buy a domain (e.g. `kumudinigandesiri.com` ~$12/yr):
- In repo Settings → Pages → Custom domain → enter your domain
- Add a CNAME record at your DNS provider pointing to `kumudini100.github.io`
