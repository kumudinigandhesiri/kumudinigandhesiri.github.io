Who I am

About

I'm a hardware technician who spends most of my day at the bench: bringing up boards, chasing down why a unit failed, and figuring out whether a signal problem is a design margin issue or a bad part. I've done this work at AMD and Apple, on ASIC bring-up and hardware validation, so I'm used to environments where precision and clear documentation both matter.

My core toolkit is SEM, curve tracer, and microscopy for physical failure analysis; oscilloscopes, DMMs, and signal generators for electrical characterization; and soldering and rework for getting boards back to spec. I also write Python and shell scripts to automate data logging, parse logs, and turn raw test data into something a team can actually use.

I hold a Master's in Management and Information Systems on top of a Bachelor's in Electronics and Communications Engineering, which is part of why I care as much about clear documentation and cross-team communication as I do about the hands-on debug work itself.

Things I've built

Self-initiated projects

Electrical Failure Signature Classifier
Python / pandas / scikit-learn / matplotlib
A rule-based and ML-assisted pipeline that sorts failing units into categories (open, short, leakage defect, marginal timing) from electrical test signatures, then flags low-confidence cases for manual physical failure analysis so SEM/FIB time gets spent where it's actually needed.
DRAM Timing Margin Analyzer
Python / pandas / NumPy
Evaluates setup/hold timing sweep data against spec limits and computes per-point margin, classifying results as PASS, MARGINAL, or FAIL. Flags marginal timing within 15% of spec limit across voltage corners to catch reliability risk before it turns into a hard failure.
PCIe LTSSM Link Training Log Parser
Python / regex / pandas
Reconstructs PCIe LTSSM state sequences from raw debug logs and flags excessive dwell time and repeated link-retraining or instability events, turning multi-thousand-line traces into a compact summary for root-cause debug.
